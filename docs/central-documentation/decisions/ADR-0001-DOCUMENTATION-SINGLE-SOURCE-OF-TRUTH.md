# ADR-0001 — Establish a Central Documentation System
- **Status:** Proposed baseline accepted for documentation structuring; repository/workspace target pending.
- **Context:** Project knowledge and governance artifacts are distributed across conversations and uploaded files.
- **Decision:** Organize project documentation beneath `3iii BUSINESS OS/3i-XaaS Central Documentation System/` using the 00–12 scope structure, decisions and evidence folders. Dropbox is the primary workspace; GitHub stores critical, version-controlled documents.
- **Consequences:** Each document has an owner/status/source; app-specific documentation is added only when app requirements are supplied.
- **Not included:** No provider configuration, source code, database, access, branch policy or production changes.
